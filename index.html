Share manual calls with everyone

Calls you pick in the status dropdown always show on this device right away. To make them show for everyone who opens the tracker, connect a GitHub token once:

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → election-tracker.
  3. Permissions → Repository → Contents: Read and write. Set it to expire in 7 days.
  4. Generate, copy, and paste it here. It is saved only in this browser.
